# Feature request: visual features

## Native menus

Instead of menus that live in the rendered window, use native windows for the local windowing system

Note: if this is problematic or too difficult, then create an app-specific, windowing-system-universal menu built into the interface window

## Waiting notifications

I'd like to see the spinning gear from the initial splash screen reused in the chat window when we're waiting for a response from the LLM.

## About splash page

We should make an "About" splash page that includes version, homepage, an ability to check for updates, and a nice spinning gear like we have elsewhere.
